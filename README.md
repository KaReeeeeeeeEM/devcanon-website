# devcanon website

The official marketing, documentation, download, and release-history site for [devcanon](https://www.npmjs.com/package/devcanon).

Live site: <https://devcanon-website.vercel.app>

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Standards

This repository was initialized with devcanon before implementation. Start at `.ai/AGENTS.md`; documentation UI follows `.ai/documentation.md`.

## Verification

```bash
npm run lint
npm run build
npx devcanon check
```
